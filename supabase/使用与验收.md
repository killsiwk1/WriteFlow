# WriteFlow 个人同步
在同一项目内使用邮箱、密码登录，唯一用户名为 3–32 位英文字母、数字或下划线，忽略大小写。每份本地学习资料绑定一个项目和账号，退出或断开后保留本机记录。共享电脑请使用独立浏览器配置文件。

1. 在 https://supabase.com/dashboard 新建自己的项目，启用 Email 登录。在项目的 Connect 或 API Keys 中取得 Project URL 和 sb_publishable_ 开头的公开密钥。
2. 打开新版 WriteFlow 的设置 → 云端同步，保存地址和密钥，点击测试连接。
3. 在「初始化数据库」复制 SQL，在自己项目的 SQL Editor 中执行一次。请使用 WriteFlow 专用项目，注册触发器会要求新用户提供用户名。复制不可用时可以直接选中 SQL，或打开同目录 schema.sql。
4. 首台设备注册。如开启邮箱验证，请先确认邮件，再输入邮箱和密码登录。首次绑定前核对邮箱。其他设备使用相同项目和同一账号登录。
5. 查看同步状态和上次同步时间。在一台设备提交答案后等到同步成功，再在另一台点击「立即同步」。离线答题仍在本机保存，下次联网会重试。
6. 修改密码在登录后操作。更换项目或账号需要独立的本地资料。退出登录保留现有题目、作文和设置。

同步包含答题事件、作答内容、依据事件计算的错题状态、练习偏好和持久化的练习会话。作文、手写的独立错题笔记、公共题库、主题、词汇库及学习时长留在本机。不同设备答同一道题会留下两次真实尝试，重传同一次作答只保存一份。当前轮次内掌握优先。重置全部进度会在同步时开始新的云端周期，各机原有答题历史留在本地。并行更换不同练习时保留先提交的云端会话，两边的答题事件分别合并。客户端增量上传，下载当前周期全部事件；个人记录量大时响应会变大。
